# Speiro 0.2.0 partial pilot candidate ? NOT RELEASED

PROVISIONAL - pending Claude review and owner approval; do not merge or publish.

This is a reviewed-direction pre-1.0 definition package, not stable-complete or production conformance. Source inventory includes all registered definitions at the pinned source commit. Synthetic examples do not prove production mapping or evidence truth. Profiles are draft/experimental even when their package version is 0.2.0.

- Consent permission uncertainty, precise missing/withdrawn parents, contribution details, assembly Provenance and metadata gaps are definition contracts. Production event capture, source completeness, token generation/storage and mapping remain P05. Mandatory contribution issued must be actual availability, never substituted from assembly or Start.
- Unknown permission is not false; missing metadata is not missing consent. Historical/no-policy interpretation remains separately governed; this build does not invent it. Consent decisions at first Start are immutable for that session.
- Identity outcomes omit biometric scores and bands. Numeric confidence remains deferred until raw scores exist, calibration is complete and disclosure approved. Simulated results are never real matches. Backend/FHIR parity remains pending where recorded.
- Unit-window outcomes derive from source-segment status, not independent window verdicts. Supervision and opaque report context are definitions, not production token or member-matching implementation.
- Non-consent exceptions are factual review/record sibling Flags without blocking. Metadata-gap Flags do not carry blocking. Capture blocking remains confined to supported first-Start restrictions; it never means treatment, payment or finalization is held.
- Pilot scope uses coarse place/POS, authorization calendar windows, factual location categories and provider-overlap exceptions. No address/coordinates in FHIR examples. Backend scope alignment is not a claim that the runtime exports this FHIR package.
- Base-R4 examples and documentary/source checks do not become complete Speiro conformance merely because the validator passes. Exact resource profiles still control; report outcome, contributor accounting and source associations need application checks.
- No publication or deployment has been approved. F-5 ruleset restoration, F-7 token scope/expiry attestation, exact-byte independent review and specific owner release approval remain gates. P04/FMT remain open.
