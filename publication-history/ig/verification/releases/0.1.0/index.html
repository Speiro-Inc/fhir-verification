Speiro Verification Implementation Guide

This experimental FHIR R4 4.0.1 scaffold establishes package identity and publication structure. It contains ImplementationGuide metadata, synthetic introductory documentation, and one fixed nonclinical Parameters notice required by this selected SUSHI/Publisher scaffold configuration. In R4, ImplementationGuide.definition is optional; its resource requirement applies when definition is present. It contains no clinical profiles, extensions, terminology, patient records, or clinical examples.

The package is not a partner-approved Level 2 release. It does not implement session document assembly, clinical validation, reports, claims adjudication, or an external FHIR server.

Speiro reports neutral session facts. Payers own claim decisions. Future definitions require separate scope approval and validation.

Package versions, application schema versions, verification-rule versions, and generator versions are independent. A package build does not change application behavior or the existing canonical evidence digest.
