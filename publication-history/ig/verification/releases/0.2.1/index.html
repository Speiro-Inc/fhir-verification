# Speiro Verification FHIR Implementation Guide 0.2.1 — partial pilot release

This package provides definitions, terminology and synthetic examples for exchanging Speiro verification facts. It contains no real client data.

This is a partial pilot release before version 1.0. It is not a complete production implementation.

- Consent edge cases are defined, but not all are produced by the application yet.
- Identity results contain no confidence scores.
- Unit results derive from session time segments, not independent per-window assessments.
- Non-consent exceptions are factual review flags and never block activity.
- Location is represented only as a place type or place-of-service category, without addresses.
- Examples are synthetic and do not establish facts about real people or sessions.
- Terminology was checked offline, without an external terminology service.
- The package reports facts only. It makes no payment decisions.
