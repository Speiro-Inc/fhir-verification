# Speiro FHIR publication destination

The authoritative source is `Speiro-Inc/ABA_Wearable` under `fhir/verification/`.
This repository holds only deployment plumbing and retained reviewed releases;
it is not an independently maintained source copy.

Initial content prepares domain bootstrap only. No package is released and the
history index is empty. Workflow dispatch and deployment require separate
approval, configured protections, domain verification, and source-read access.
